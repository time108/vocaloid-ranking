APIキーの取得方法（無料）

  3. 「APIとサービス」→「ライブラリ」→「YouTube Data API v3」を有効化
  4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
  5. 発行されたキーをコピーして上の欄に貼り付け
